# Telegram Sticker Fitting Bot

Telegram-бот, который принимает изображения, GIF и видео и автоматически подготавливает их под формат стикеров Telegram.

Бот не создаёт sticker pack — он сразу возвращает готовый стикер в сообщении, чтобы его можно было использовать дальше.

## Возможности

### Статичные изображения

Бот принимает:

* фотографии;
* PNG;
* JPEG/JPG;
* WEBP;
* изображения, отправленные как файл.

На выходе бот отправляет статичный `.WEBP`-стикер.

Изображение автоматически масштабируется так, чтобы помещаться в размер `512×512` без искажения пропорций. Если исходное изображение меньше квадратного холста, свободное пространство остаётся прозрачным.

Telegram поддерживает статичные стикеры в форматах PNG и WEBP. Для стикера одна из сторон должна быть ровно 512 px, а другая — не больше 512 px.

### GIF и видео

Бот принимает:

* GIF;
* MP4 и другие видеоформаты;
* видео, отправленные как файл.

На выходе получается видео-стикер `.WEBM`, закодированный в VP9.

Видео автоматически:

* обрезается до 3 секунд;
* масштабируется под `512×512`;
* сохраняет исходные пропорции;
* получает прозрачные поля при необходимости;
* ограничивается 30 FPS;
* очищается от аудиодорожки;
* кодируется в VP9 WebM;
* сжимается до допустимого размера.

По требованиям Telegram video sticker должен быть в WebM с VP9, без аудио, длительностью не более 3 секунд и частотой до 30 FPS. Одна сторона должна быть 512 px, размер файла — не более 256 КБ.

## Архитектура

```text
Telegram
   │
   ├── Photo ────────┐
   ├── Image file ───┤
   ├── GIF ──────────┤
   └── Video ────────┤
                     ▼
                 aiogram
                     │
                Media Router
                /           \
               /             \
              ▼               ▼
     Image Processor    Video Processor
              │               │
              ▼               ▼
            WEBP           WEBM / VP9
              │               │
              └───────┬───────┘
                      ▼
              Telegram sticker
```

Обработка медиа отделена от Telegram-логики. Это позволяет тестировать процессоры независимо от бота.

## Технологии

* Python 3.12+
* [aiogram 3](https://docs.aiogram.dev/)
* [Pillow](https://python-pillow.org/)
* [FFmpeg](https://ffmpeg.org/)

## Установка

### 1. Клонировать репозиторий

```bash
git clone <repository-url>
cd telegram-sticker-fitting
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate
```

Для Windows:

```bash
.venv\Scripts\activate
```

### 3. Установить Python-зависимости

```bash
pip install -r requirements.txt
```

### 4. Установить FFmpeg

На macOS:

```bash
brew install ffmpeg
```

Проверить установку:

```bash
ffmpeg -version
```

На Linux:

```bash
sudo apt update
sudo apt install ffmpeg
```

### 5. Создать Telegram-бота

Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.

Создайте файл `.env`:

```env
BOT_TOKEN=your_telegram_bot_token
```

Файл `.env` не должен попадать в Git.

## Запуск

Запустите бота из корня проекта:

```bash
python -m bot.main
```

После запуска отправьте боту:

```text
/start
```

В ответ бот предложит отправить изображение, GIF или видео.

## Как работает обработка

### Изображение

```text
Input image
     ↓
Pillow
     ↓
EXIF rotation
     ↓
Resize
     ↓
512×512 transparent canvas
     ↓
WEBP
     ↓
Telegram sticker
```

Исходные пропорции изображения сохраняются.

### GIF / Video

```text
GIF / Video
     ↓
FFmpeg
     ↓
max 3 seconds
     ↓
resize + padding
     ↓
max 30 FPS
     ↓
remove audio
     ↓
VP9
     ↓
WEBM
     ↓
Telegram sticker
```

## Обратная связь пользователю

Поскольку обработка видео может занимать некоторое время, бот сначала отправляет сообщение:

```text
⏳ Получил файл! Обрабатываю его...
```

После завершения обработки отправляется готовый стикер.

## Ограничения

Текущая версия проекта ориентирована прежде всего на корректное преобразование формата.

Удаление фона у обычных фотографий пока не выполняется. Если пользователь отправляет JPG с фоном, сам фон изображения сохраняется; прозрачными являются свободные области вокруг изображения.

Для статичных стикеров Telegram рекомендует прозрачный фон, но его наличие не создаётся автоматически простым преобразованием JPG в WEBP.

## Почему WEBM

Для анимированных стикеров используется именно video sticker в формате `.WEBM`.

Telegram поддерживает video stickers, закодированные VP9 в контейнере WebM. Такой стикер может содержать альфа-канал, не должен иметь аудиодорожку и должен соответствовать ограничениям по размеру, разрешению, FPS и длительности.

## Development

Обработка медиа вынесена в отдельные модули:

```text
processors/image.py
```

отвечает за изображения,

```text
processors/video.py
```

отвечает за GIF и видео,

```text
processors/validation.py
```

предназначен для проверки готового файла.

Telegram-логика находится в:

```text
bot/handlers.py
```

а запуск приложения — в:

```text
bot/main.py
```

Такое разделение позволяет изменять алгоритмы обработки файлов, не переписывая Telegram handlers.
